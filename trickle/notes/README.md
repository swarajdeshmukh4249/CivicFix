# Motion - Smart Note-Taking SaaS

## Overview
This project showcases Motion, an AI-powered note-taking SaaS platform. The landing page features interactive glowing effect components built with React and Tailwind CSS that highlight key product features.

## Project Structure
- **lib/utils.js** - Utility functions for class name merging
- **components/ui/glowing-effect.js** - Core glowing effect component
- **components/glowing-effect-demo-2.js** - Demo implementation with grid layout
- **app.js** - Main application component
- **index.html** - Entry point with all necessary dependencies

## Features
- AI-Powered Organization showcase
- Real-Time Collaboration features
- Enterprise-Grade Security highlights
- Lightning-Fast Search capabilities
- Cross-Platform Sync demonstration
- Interactive mouse-responsive glowing effects
- Grid-based responsive layout
- Dark/light theme support
- Smooth animations using Motion library

## Dependencies
- React 18
- Tailwind CSS
- Motion library for animations
- Lucide icons

## Setup Notes
This project follows a component-based architecture similar to shadcn/ui but adapted for vanilla React without TypeScript. All components are written in plain JavaScript and use React.createElement for JSX-like functionality.

## Usage
The landing page showcases 5 key features of Motion's note-taking platform through interactive cards with glowing effects that activate when the mouse is near them. Each card highlights a different aspect of the SaaS product.
